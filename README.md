# Pylothouse Help Centre

A searchable help library for reader, creator, safety and account topics, plus a support contact route.

## Pages

- `/` - help-centre overview
- `/articles` - searchable article index
- `/articles/[slug]` - individual guidance
- `/contact` - support email draft

Articles are general guidance, not a promise that a specific platform feature is available. Current product options and policies must be confirmed on Pylothouse. Contact opens an email draft to `support@pylothouse.com`; the site does not send or store the request.

```bash
npm install
npm run dev
```
